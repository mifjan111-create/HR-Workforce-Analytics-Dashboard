# HR-Workforce-Analytics-Dashboard
Power BI dashboard analyzing employee attrition, workforce demographics, salary trends, and department performance.

**Business Problem**

HR leaders require workforce insights to monitor employee attrition, workforce demographics, salary trends, and departmental performance.

**Tools Used**

-Power BI

-Excel

-DAX

**Dashboard KPIs**

-Total Employees

-Attrition Count

-Attrition Rate

-Average Age

-Average Experience

**Key Insights**

-Attrition was highest in selected departments.

-Majority of employees belonged to the 26-35 age group.

-Salary level showed a relationship with attrition patterns.

-Workforce distribution varied significantly across departments.

**Dashboard Features**

-Attrition Analysis

-Department Analysis

-Age Group Distribution

-Gender Analysis

-Salary Analysis

-Workforce Demographics
